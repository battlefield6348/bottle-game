# Color Mart 倒水排序

以純 HTML / Canvas / ES Modules 製作的 Water Sort 益智遊戲，不需建置步驟，直接部署於 GitHub Pages。

## 玩法

點選一個瓶子將它拿起，再點另一個瓶子把頂端同色的水倒過去。目標瓶必須是空瓶，或頂端顏色相同且還有空間。每瓶裝滿單一顏色時會自動封蓋，所有瓶子都封蓋或清空即過關。

## 關卡設計

- **隨機產生、保證有解**：每關由隨機種子產生候選盤面，交給深度優先求解器驗證，只採用找得到解的盤面。找不到時會依序放寬條件（減少冰凍、鎖鏈瓶，或增加空瓶），一定能產出可解關卡。
- **難度遞增**：顏色數從 3 色逐步增加到 12 色；後期會從多個有解候選中挑出求解最費力的盤面。
- **進度保存**：關卡號碼與隨機種子存在瀏覽器，重玩同一關會得到相同盤面。

| 機制 | 解鎖關卡 | 規則 |
| --- | --- | --- |
| 遮擋瓶 | 第 4 關 | 底層以「?」隱藏，倒掉上層後才揭露；遮擋層不會跟著一起倒出 |
| 綁定色瓶 | 第 8 關 | 瓶框與底座標示的顏色，是該瓶唯一能接受的顏色；第 20 關起取代一般空瓶 |
| 鎖鏈瓶 | 第 12 關 | 鎖頭上的顏色完成後才能使用 |
| 冰凍瓶 | 第 16 關 | 完成數字所示數量的顏色後解凍 |

## 節慶主題

每年 10 月至 11/1 自動換上萬聖節主題：紫夜背景、月亮、飛舞的蝙蝠、垂降的蜘蛛、會閃爍的南瓜燈與對話卡蜘蛛網。裝飾全在 Canvas 後方，不影響點擊。網址加上 `?theme=halloween` 或 `?theme=default` 可強制開關。

## 動畫

倒水時液面永遠保持水平：渲染器把瓶身多邊形依當下姿勢轉成世界座標，再以水平線裁切、二分搜尋出各色層的液面高度。傾倒角則由「剩餘水量剛好貼齊瓶口」反推，所以倒水過程中瓶身會隨水量連續加深傾斜，不會溢出也不會跳動。關卡產生與提示求解在 Web Worker 中執行，避免阻塞動畫。

## 開發

```bash
npm test        # 執行規則、求解器、產生器、幾何與版面配置的單元測試
npm run serve   # 於 http://localhost:8080 啟動本機伺服器（ES Modules 需經 HTTP 載入）
```

| 檔案 | 職責 |
| --- | --- |
| `src/rules.js` | 倒水規則與各特殊機制判定 |
| `src/solver.js` | 求解器（關卡驗證與提示） |
| `src/generator.js` | 難度曲線與保證有解的關卡產生 |
| `src/geometry.js` | 液面高度與傾倒角度的幾何計算 |
| `src/layout.js` | 依螢幕尺寸排列瓶子 |
| `src/renderer.js` | Canvas 繪製瓶子、液體、水柱與特效 |
| `src/game.js` | 遊戲狀態、輸入與動畫時間軸 |
| `src/worker.js` | 背景執行關卡產生與提示 |
| `src/main.js` | 頁面 UI、存檔與 Worker 串接 |
| `src/season.js` | 判斷是否啟用節慶主題 |

## 部署

推送到 `main` 時，GitHub Actions 會先跑測試，再把 `index.html`、`styles.css`、`src/` 發布到 GitHub Pages（儲存庫 Settings → Pages 的 Source 需設為 GitHub Actions）。
